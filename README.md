📊 Swiggy Sales Analysis Dashboard | Excel Project

This project showcases an end-to-end Excel-based sales analytics dashboard created using Swiggy food delivery data. The objective of this project is to analyze business performance, customer behavior, and regional demand using Excel as a business intelligence tool.

The dashboard provides a consolidated view of key performance indicators (KPIs) including Total Sales, Total Orders, Average Order Value, Average Customer Rating, and Rating Count. These KPIs help in understanding overall revenue performance and customer satisfaction levels at a glance.

To identify time-based trends, the project includes Monthly, Weekly, and Daily Sales Analysis. This helps in understanding seasonal patterns, peak order days, and demand fluctuations across different time periods. Such insights are valuable for planning promotions, staffing, and operational efficiency.

The dashboard also analyzes sales distribution by food type, comparing Veg and Non-Veg categories to understand customer preferences. Additionally, top-performing cities are highlighted to identify high-revenue urban markets and compare their contribution to total sales.

A state-wise sales analysis is visualized using a map chart, enabling a clear understanding of regional performance across India. This geographic analysis supports decision-making related to market expansion, regional marketing strategies, and logistics optimization.

Quarter-wise analysis is included to compare sales, average ratings, and order volume across different quarters. Conditional formatting is used to quickly identify high and low performance areas, making the dashboard easy to interpret for both technical and non-technical users.

The primary goal of this project is to demonstrate practical Excel skills for business analytics, converting raw data into meaningful insights that support data-driven decision-making. This project is well-suited for Business Analyst, Data Analyst, and MBA student portfolios, as well as interview and resume showcases.
